# Puyo Puyo 2

뿌요뿌요 투(通) 스타일의 대전 퍼즐 게임 (브라우저, HTML5 Canvas). 개발 서버에서는 `/puyo/`로 열립니다.

## 실행

저장소 루트에서:

```bash
npm install
npm run puyo:assets -- ../taebo-games-puyo-puyo2-assets   # 원본 데이터 변환 (최초 1회)
npm start                                                  # 개발 서버
```

변환 결과(`puyo/assets/p2/`)가 없으면 게임이 시작되지 않습니다.

## 규칙 (뿌요뿌요 투)

- 6×12 필드. 같은 색 4개 이상이 이어지면 터지고, 위의 뿌요가 떨어져 또 터지면 연쇄입니다.
- 점수: `10 × 터진 수 × (연쇄 보너스 + 색 보너스 + 연결 보너스)`. 연쇄 보너스 0, 8, 16, 32, 64, 96, 128, …
- 점수 70점마다 방해뿌요 1개를 상대에게 보냅니다. 내게 올 방해뿌요가 있으면 먼저 그만큼 상쇄합니다.
- 상대가 보낸 방해뿌요는 상대의 연쇄가 끝난 뒤, 내가 다음 뿌요를 놓은 다음에 떨어집니다(한 번에 최대 30개).
- 필드를 전부 지우면(ALL CLEAR) 다음 연쇄에 방해뿌요 30개가 더해집니다.
- 왼쪽에서 세 번째 줄 맨 위(✕ 표시)가 막히면 집니다.
- 숨은 13번째 줄 위의 뿌요는 터지지 않습니다. 시간이 지날수록 떨어지는 속도가 빨라집니다.
- 기본 2선승(메뉴에서 1판·3선승으로 바꿀 수 있음).

수치는 `js/board.js` 맨 위에 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 옮기기 (누르고 있으면 계속) |
| ↓ | 빨리 내리기 (한 칸에 1점) |
| Space | 바로 내리기: 바닥까지 한 번에 내려가 바로 붙음 (한 칸에 1점) |
| X / ↑ | 오른쪽으로 돌리기 |
| Z | 왼쪽으로 돌리기 |
| Esc | 메뉴 (컴퓨터 대전은 멈춤) |

- 벽이나 뿌요에 막히면 옆으로 밀려나며 돌고, 양옆이 다 막힌 한 칸 틈에서는 두 번 누르면 위아래가 뒤집힙니다.
- 한 키보드 2인: 왼쪽 A D S + F(왼쪽 돌리기) G/W(오른쪽 돌리기) + E(바로 내리기), 오른쪽 ← → ↓ + `,` `.` / ↑ + `/`(바로 내리기)
- 휴대폰(주 대상): 맨 아래 한 줄에 버튼 5개
  - 왼손 ◀ ▶ ▼: 옮기기(누르고 있으면 계속), 빨리 내리기(누르는 동안)
  - 오른손 ⟳: 돌리기(한 방향, 누를 때마다 90°씩). 바로 내리기 버튼은 실수로 눌리기 쉬워서 뺐고,
    필드를 아래로 휙 튕기면 바로 내려갑니다.
  - 양옆이 막힌 한 칸 틈에서는 ⟳를 빠르게 두 번 누르면 위아래가 뒤집힙니다.
  - 필드 위 손가락: 옆으로 끌면 한 칸씩, 천천히 아래로 끌면 빨리, 아래로 휙 튕기면 바로 내리기, 톡 치면 돌리기
- 화면: 세로로 들면 맨 위 상태바(가운데 플레이 시간과 이긴 판 별, 왼쪽 내 이름·점수·연쇄, 오른쪽 상대),
  그 아래 내 필드가 크게, 옆에 NEXT와 상대 필드가 작게, 그 아래 두 캐릭터가 마주 서고(이름·이긴 판),
  맨 아래 버튼 줄. 가로로 들면 원작 화면 그대로이고 버튼은 양쪽 아래 여백에, 플레이 시간은 위 가운데에 나옵니다.
- 캐릭터: 가만히 있지 않고 숨 쉬듯 움직이고, 연쇄 때 뛰고, 방해뿌요가 많이 오면 움찔하고, 이기면 계속 뛰고, 지면 쓰러집니다.
  말풍선으로 한마디 합니다: 아르르는 연쇄마다 주문(파이어!, 아이스 스톰!, … 바요엔~!), 다른 캐릭터는 '받아라!' 같은 공통 대사,
  방해뿌요가 올 때 '으앗!', 전부 지우면 '싹쓸이!', 이기면/지면 한마디. 대사는 `js/render.js`의 `LINES`에 있습니다.
- 상태바의 연쇄: 연쇄가 터지는 동안은 'N연쇄!'(노랑), 평소에는 이번 판 최대 연쇄를 보여 줍니다.

## 컴퓨터

`js/ai.js`. 뿌요를 놓을 수 있는 모든 곳을 시험해 연쇄를 끝까지 돌려 보고, 남은 모양(같은 색 붙음, 가운데 높이, 한두 개만 더
넣으면 터질 연쇄 크기)을 점수로 매깁니다. 쉬움은 2연쇄면 쏘고 느리게 움직이며, 보통은 3연쇄, 어려움은 5연쇄를 노리고 다음 뿌요까지
내다봅니다. 위험하거나 방해뿌요가 오고 있으면 바로 쏩니다.

## 그래픽

메뉴의 **그래픽**에서 고릅니다. 기본은 원작 그대로입니다.

- **원작 그대로**: 원작 필드 틀(8종 중 무작위), 원작 뿌요 그림(연결 모양 16가지), 원작 점수 글꼴, '연쇄' 글자, 방해뿌요 예고 아이콘,
  '싹쓸이!', 터질 때의 작은 뿌요 고리를 씁니다. 4배 Scale2x 그림을 부드럽게 줄여 그려서 큰 화면에서도 계단이 덜 보입니다.
  휴대폰을 세로로 들면 틀 전체가 들어가지 않아서, 틀에서 필드 테두리와 NEXT 창을 오려 다시 배치합니다.
- **깔끔하게 (모던)**: 뿌요를 벡터로 그립니다(광택 그라데이션, 이어진 뿌요는 몸으로 연결). 필드는 반투명 유리 패널,
  배경은 원작 스테이지 그림을 흐리게 깔고, 떨어질 자리 점·축 뿌요 표시·연쇄 글자·터지는 입자 같은 요즘 연출을 넣었습니다.

캐릭터 얼굴·SD 그림(35명)은 둘 다 원작 그림입니다. 화면은 원작과 같은 640×480 배치를 기기 해상도로 그립니다.

## 화면 흐름

인트로(화면을 터치해서 시작) → 처음 화면(내 캐릭터, 이름, 랭킹·점수·전적·최대 연쇄, 캐릭터 바꾸기·랭킹) →
**게임하러 가기** → 메뉴(컴퓨터·한 키보드 2인 대전, 온라인 대전) → 대기실 → 게임 → 결과.

## 온라인 대전

웜즈와 같은 방식입니다. 메뉴의 **친구와 온라인 대전**에서 한 명이 **방 만들기**를 누르면 4자리 방 번호가 나오고 대기실이 열립니다.
친구는 방 번호로 **참가**하거나, 방장이 **초대 링크 보내기**로 보낸 링크(`?room=1234`)를 열면 번호가 채워져 있습니다.

- 대기실: 두 사람의 캐릭터·이름이 나오고, 게임 시작 전까지 각자 **내 캐릭터 바꾸기**로 캐릭터를 바꿀 수 있습니다(서로 화면에 바로 반영).
  승부(1판·2선승·3선승)는 방장이 고릅니다. 방장이 **게임 시작**을 누르면 시작, 판이 끝나면 방장이 **다시 하기**나 **대기실로**를 고릅니다.
- 방 번호는 1만 개뿐이라, 방장이 번호를 뽑은 뒤 잠깐 같은 번호의 다른 방이 있는지 보고 있으면 다시 뽑습니다(웜즈와 같음).
- Supabase Realtime 채널(웜즈·포트리스와 같은 프로젝트, 채널 이름 앞 `tbpuyo2-`)로 broadcast와 presence만 씁니다. 설정은 `js/net.js` 맨 위입니다.
- 둘이 같은 뿌요 순서를 받습니다(판마다 방장이 정한 시드). 각자 자기 필드를 자기 화면에서 계산하고, 상대에게 필드 상태를
  초당 20번 보냅니다. 방해뿌요는 메시지(`atk`: 개수, `rel`: 연쇄 끝)로 오가서 받는 쪽에서 상쇄·낙하합니다.
- 판의 승패와 다음 판 시작은 방장이 정합니다. 메시지가 빠져도 되도록 판 시작은 상대 필드가 같은 판으로 올 때까지 반복해서 보냅니다.

## 랭킹

웜즈처럼 이름으로 셉니다(계정 없음, 같은 이름이면 같은 사람). 온라인 1:1이 끝나면 방장 화면이 두 사람의 결과를 기록합니다.

- 점수: 승리 +3점, 패배 0점. 이번 달 / 전체 탭, 승패와 최대 연쇄도 보여 줍니다.
- Supabase 테이블 `puyo_results`(한 판에 한 사람당 한 줄: 이름, 캐릭터, 승패, 점수, 이긴 판 수, 총점, 최대 연쇄)와
  합계 뷰 `puyo_ranking`, `puyo_ranking_month`(한국 시간 기준 이번 달). 누구나 읽고 추가할 수 있고, 고치거나 지울 수는 없습니다
  (`worms_results`와 같은 규칙, 기록 시각이 지금 ±5분일 때만 추가).
- 컴퓨터 대전과 한 키보드 2인은 기록하지 않습니다.

## 소리와 음악

- 효과음·음성은 원작 WAV 그대로입니다. 파일에 이름이 없어 길이와 모양으로 골랐습니다: 연쇄음 7단계(`PUYO01_02`~`08`, 음이 올라감)는 확실하고,
  나머지(옮기기·돌리기·착지·방해뿌요·상쇄·전멸·짐)와 아르르의 연쇄 주문, 다른 캐릭터 대사(`VOICnnS/L`)는 추정입니다.
  `?sfx`를 붙여 열면(`/puyo/?sfx`) 모든 소리와 곡을 눌러 들을 수 있습니다. 어떤 게 무엇인지 알려 주면 `js/sound.js`에서 맞춥니다.
- 음악은 원작 MIDI 19곡을 브라우저 안의 작은 신시사이저(`js/midi.js`, WebAudio 오실레이터)로 연주합니다. 게임 중에는 본편 곡 중
  반복 곡을 무작위로 틉니다. 사운드폰트를 쓰면 원작에 더 가깝게 들리게 바꿀 수 있습니다.
